# KOVA — Event Discovery & Ticketing Platform

> 🚧 **Currently in active development**

KOVA is a premium, mobile-first platform for discovering cultural events and managing ticketing experiences across Abidjan and, ultimately, West Africa.

The product is designed to make event discovery feel visual, intuitive, and community-driven while giving creators practical tools to publish events and manage multiple ticket types.

## Product vision

KOVA brings the discovery, cultural context, and transaction journey into one experience:

- Curated event discovery and immersive event pages
- Artist and emerging-talent profiles
- Interactive location and map experiences
- Creator mode with flyer upload and live preview
- Multiple ticket types and event publishing
- Responsive navigation across mobile and desktop

## Current prototype

The public prototype is the active visual and functional reference for the product. It is being refined iteratively with a focus on mobile-first usability, premium interface design, accessibility, performance, and reliable event-creation flows.

**[Open the live prototype](https://donovankore.github.io/kova-event-discovery-platform/)**

## Technology

The current prototype is built with HTML, CSS, and JavaScript. The planned production architecture includes Next.js, React, PostgreSQL/Supabase, authentication, storage, and payment integrations suitable for local and international users.

## Status

KOVA is an independent product project in active development. The repository remains public so progress, design decisions, and functional iterations can be reviewed over time.
